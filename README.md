# Noxus Department

> An immersive 360°/VR biology project combining scientific research, fictional narrative, 3D environments, audiovisual production, and web development.

## 🧬 About the Project

Noxus Department began as a school seminar about fungi, but the team decided to develop it beyond a conventional presentation.

The project combines real scientific content with a fictional narrative set in **2043**, creating the **Noxus Department**, a fictional research organization, and using multiple forms of media to build its universe.

The final project brings together:

- Scientific research
- Fictional narrative and scriptwriting
- Visual identity
- Graphic materials
- 3D environments
- Audiovisual production
- Chroma key
- Web development
- 360° / VR

The project was developed by a team of **6 students**.

## 🎯 Concept

The project has two interconnected layers:

**Scientific layer** — real information about fungi provides the scientific basis of the seminar.

**Narrative layer** — this information is transformed into a fictional experience involving an experimental organism and a containment failure in 2043.

The two layers were developed together: science provides the foundation, while the narrative turns it into a visual and immersive experience.

## 🌎 The Experience

The narrative progresses through five environments:

**Forest → City → Bedroom → News Broadcast → Laboratory**

| Environment | Function |
|---|---|
| Forest | First contact with the organism |
| City | Expansion of the phenomenon |
| Bedroom | Bringing the situation closer to the viewer |
| News Broadcast | Public disclosure |
| Abandoned Laboratory | Consequence and containment failure |

## 👥 Team

The project was developed collaboratively by a team of 6 students, with work involving research, scientific content, scriptwriting, narrative construction, visual identity, graphic materials, 3D modeling, audiovisual production, web development, VR, and presentation.

## 🎬 Final Result

The final experience combines:

**Science + Fiction + Narrative + Design + Audiovisual + 3D + Web + VR**

The website, documents, posters, audiovisual material, 3D environments, and VR experience were designed to belong to the same fictional universe.
